# FPGA Digital Design

A collection of Verilog RTL designs and simulation-oriented modules developed during FPGA and digital design laboratory work.

## Contents

- Arithmetic units
- Sequential multipliers
- RAM and file-based memory handling
- Synchronous and asynchronous FIFO
- Mealy and Moore FSMs
- FIR filters and Sobel edge detection
- Digital clock and seven-segment display designs

## HDL

- Verilog HDL
- Simulation-oriented testbenches
- Quartus Prime / ModelSim workflow

## Scope

This repository is organized from the FPGA design work documented in the accompanying lab material. The implementations are preserved as closely as practical while separating reusable RTL from testbenches.
